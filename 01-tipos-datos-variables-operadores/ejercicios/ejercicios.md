# 📝 Ejercicios: Tipos de Datos, Variables y Operadores

En esta sección encontrarás ejercicios prácticos para reforzar el uso de **tipos de datos, variables y operadores en C#**.

> 💡 **Recomendación:** intenta resolver cada ejercicio por tu cuenta antes de consultar los ejemplos de la clase.

---

## 🟢 Ejercicio 1 — Datos personales

Crea un programa que almacene en variables los siguientes datos:

* Nombre
* Edad
* Altura
* Inicial del apellido
* Si es estudiante o no

Luego muestra todos los datos en la consola.

---

## 🟢 Ejercicio 2 — Operaciones básicas

Declara dos variables numéricas y realiza las siguientes operaciones:

* Suma
* Resta
* Multiplicación
* División
* Módulo

Muestra cada resultado en la consola.

---

## 🟡 Ejercicio 3 — Área de un rectángulo

Crea un programa que almacene la **base** y la **altura** de un rectángulo.

Calcula y muestra:

* Área
* Perímetro

**Fórmulas:**

```text
Área = base × altura
Perímetro = 2 × (base + altura)
```

---

## 🟡 Ejercicio 4 — Conversión de temperatura

Crea un programa que almacene una temperatura en grados **Celsius** y conviértela a **Fahrenheit**.

Utiliza la siguiente fórmula:

```text
Fahrenheit = (Celsius × 9 / 5) + 32
```

Muestra la temperatura original y el resultado.

---

## 🟡 Ejercicio 5 — Promedio de calificaciones

Declara tres variables que representen las calificaciones de un estudiante.

Calcula el promedio y muestra el resultado en la consola.

El programa debe trabajar con valores decimales.

---

## 🟠 Ejercicio 6 — Precio de un producto

Una tienda necesita calcular el precio final de un producto.

Declara variables para:

* Precio del producto
* Porcentaje de descuento

Calcula:

1. El monto del descuento.
2. El precio final después del descuento.

Muestra ambos resultados.

---

## 🟠 Ejercicio 7 — Conversión de segundos

Crea un programa que reciba una cantidad de segundos almacenada en una variable.

Convierte esa cantidad a:

* Horas
* Minutos
* Segundos restantes

**Ejemplo:**

```text
Entrada:
3665 segundos

Resultado:
1 hora
1 minuto
5 segundos
```

---

## 🔴 Ejercicio 8 — Intercambio de valores

Declara dos variables enteras:

```text
a = 10
b = 20
```

Intercambia sus valores de manera que al finalizar:

```text
a = 20
b = 10
```

Muestra los valores antes y después del intercambio.

---

## 🔴 Ejercicio 9 — Expresión matemática

Crea un programa que declare las variables necesarias para resolver la siguiente expresión:

```text
resultado = (a + b) × c / d
```

Utiliza valores diferentes para cada variable y muestra el resultado.

Presta atención al **orden de las operaciones**.

---

## 🔴 Ejercicio 10 — Calculadora de sueldo

Una empresa necesita calcular el sueldo final de un trabajador.

Declara variables para:

* Sueldo básico
* Bono
* Descuento

Calcula el sueldo final utilizando:

```text
Sueldo final = Sueldo básico + Bono - Descuento
```

Muestra en pantalla cada valor y el sueldo final.

---

## 📌 Desafío

Crea un programa que calcule el **precio final de una compra**.

El programa debe manejar:

* Precio de tres productos.
* Cantidad comprada de cada producto.
* Subtotal.
* Descuento.
* Total a pagar.

Intenta utilizar diferentes tipos de datos según corresponda.

```text
-

```

```text

```
