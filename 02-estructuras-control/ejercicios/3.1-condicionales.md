# Ejercicios Prácticos — Tema 3.1: Estructuras Condicionales

**Instrucciones generales:**
Para cada uno de los siguientes ejercicios debes:

1. Diseñar el algoritmo (identificar entradas, salidas y la lógica de decisión).
2. **Implementarlo en PSeint.**
3. **Implementarlo en C#.**
4. Probar tu programa con al menos 3 casos de prueba distintos (incluyendo casos límite).

> 📌 Cada ejercicio debe entregarse **en ambos lenguajes**: el diagrama/pseudocódigo en PSeint y el código funcional en C#.

## Ejercicio 1 — Número par o impar

**Enunciado:**
Desarrollar un algoritmo que solicite al usuario un número entero y determine si es **par** o **impar**.

**Requisitos:**
- Debe usar el operador módulo (`%` en C#, `MOD` en PSeint).
- Debe mostrar un mensaje claro indicando el resultado (ejemplo: *"El número 8 es par"*).

**Entregable:**
- [ ] Algoritmo en PSeint
- [ ] Código en C#

## Ejercicio 2 — Clasificación de triángulos

**Enunciado:**
Desarrollar un algoritmo que reciba las **longitudes de los tres lados** de un triángulo y determine de qué tipo es, según el siguiente criterio:

| Condición | Tipo de triángulo |
|---|---|
| Los tres lados son iguales | Equilátero |
| Exactamente dos lados son iguales | Isósceles |
| Los tres lados son diferentes | Escaleno |

**Requisitos:**
- Debe usar estructuras `if / else` o `if / else if` (en C#) y `Si / SiNo` (en PSeint).
- Debe validar que ningún lado sea menor o igual a 0; si lo es, mostrar un mensaje de error y no continuar con la clasificación.

**Entregable:**
- [ ] Algoritmo en PSeint
- [ ] Código en C#

## Ejercicio 3 — Costo de envío según el peso

**Enunciado:**
Una empresa de paquetería cobra el envío según el peso del paquete (en kilogramos), de acuerdo a la siguiente tabla:

| Peso (kg) | Costo |
|---|---|
| 0 - 5 | $5.00 |
| 5.01 - 15 | $12.00 |
| 15.01 - 30 | $20.00 |
| Más de 30 | $35.00 |

Desarrollar un algoritmo que solicite el peso del paquete y muestre el costo correspondiente.

**Requisitos:**
- Debe usar `if / else if / else` (C#) y su equivalente anidado en PSeint.
- Debe validar que el peso ingresado no sea negativo.

**Entregable:**
- [ ] Algoritmo en PSeint
- [ ] Código en C#

## Ejercicio 4 — Menú de operaciones básicas con `switch`

**Enunciado:**
Desarrollar un algoritmo que muestre un menú con las siguientes opciones y, según la opción elegida por el usuario, pida dos números y realice la operación correspondiente:

```
1. Sumar
2. Restar
3. Multiplicar
4. Dividir
```

**Requisitos:**
- Debe usar obligatoriamente `switch` en C# y `Segun` en PSeint (no usar `if-else` para el menú).
- En el caso de la división, debe validar que el segundo número no sea 0 (para evitar división entre cero).
- Si el usuario ingresa una opción fuera del menú (por ejemplo, 5), debe mostrar un mensaje indicando que la opción no es válida (usar `default` / `De Otro Modo`).

**Entregable:**
- [ ] Algoritmo en PSeint
- [ ] Código en C#

## Ejercicio 5 — Elegibilidad para un descuento

**Enunciado:**
Una tienda ofrece un descuento especial a sus clientes según las siguientes condiciones, que deben cumplirse **todas** para aplicar el descuento:

- El cliente debe ser mayor de edad (18 años o más).
- El monto de la compra debe ser mayor o igual a $50.
- El cliente debe tener una tarjeta de membresía activa (sí/no).

Desarrollar un algoritmo que solicite la edad, el monto de la compra y si tiene membresía activa, y determine si el cliente **recibe el 15% de descuento** o no.

**Requisitos:**
- Debe usar operadores lógicos: `&&` (AND) en C# y `Y` en PSeint, para combinar las tres condiciones.
- Debe mostrar el monto final a pagar (con o sin descuento aplicado).

**Entregable:**
- [ ] Algoritmo en PSeint
- [ ] Código en C#
