# Ejercicios Prácticos — Tema 3.2: Bucles e Iteraciones

**Instrucciones generales:**
Para cada uno de los siguientes ejercicios debes:

1. Diseñar el algoritmo (identificar entradas, salidas y qué tipo de bucle es más adecuado).
2. **Implementarlo en PSeint.**
3. **Implementarlo en C#.**
4. Probar tu programa con al menos 3 casos de prueba distintos (incluyendo casos límite).

> 📌 Cada ejercicio debe entregarse **en ambos lenguajes**: el diagrama/pseudocódigo en PSeint y el código funcional en C#.

---

## Ejercicio 1 — Tabla de multiplicar

**Enunciado:**
Desarrollar un algoritmo que solicite al usuario un número entero y muestre su **tabla de multiplicar** del 1 al 10.

**Ejemplo de salida (para el número 5):**
```
5 x 1 = 5
5 x 2 = 10
...
5 x 10 = 50
```

**Requisitos:**
- Debe usar obligatoriamente un bucle `for` en C# y `Para` en PSeint (se conoce de antemano cuántas repeticiones son: 10).

**Entregable:**
- [ ] Algoritmo en PSeint
- [ ] Código en C#

## Ejercicio 2 — Factorial de un número

**Enunciado:**
Desarrollar un algoritmo que solicite un número entero **no negativo** y calcule su **factorial** (por ejemplo: 5! = 5×4×3×2×1 = 120).

**Requisitos:**
- Debe usar un bucle `for` o `while` (a elección propia, pero debe justificar cuál usó y por qué).
- Debe validar que el número ingresado no sea negativo (el factorial no está definido para negativos).
- Caso especial: el factorial de 0 es 1.

**Entregable:**
- [ ] Algoritmo en PSeint
- [ ] Código en C#

---

## Ejercicio 3 — Validación de contraseña con reintentos

**Enunciado:**
Desarrollar un algoritmo que solicite al usuario ingresar una contraseña. Si la contraseña ingresada **no coincide** con la contraseña correcta (por ejemplo: `"clave123"`), debe pedirla nuevamente. El programa debe seguir pidiendo la contraseña **hasta que el usuario la ingrese correctamente**.

**Requisitos:**
- Debe usar obligatoriamente `do-while` en C# y `Repetir...Hasta Que` en PSeint, ya que el bloque debe ejecutarse **al menos una vez**.
- Al finalizar (contraseña correcta), debe mostrar un mensaje de bienvenida.
- Opcional (reto extra): limitar a un máximo de 3 intentos y bloquear el acceso si se supera.

**Entregable:**
- [ ] Algoritmo en PSeint
- [ ] Código en C#

---

## Ejercicio 4 — Suma de números pares en un rango

**Enunciado:**
Desarrollar un algoritmo que solicite al usuario un **número inicial** y un **número final**, y calcule la suma de todos los números **pares** que se encuentran dentro de ese rango (incluyendo los extremos si son pares).

**Ejemplo:** Si el rango es de 1 a 10, los números pares son 2, 4, 6, 8, 10 → suma = 30.

**Requisitos:**
- Debe combinar un bucle (`for` / `Para`) con una estructura condicional (`if` / `Si`) dentro del mismo, para verificar si cada número es par.
- Debe validar que el número inicial sea menor o igual al número final; si no, mostrar un mensaje de error.

**Entregable:**
- [ ] Algoritmo en PSeint
- [ ] Código en C#

## Ejercicio 5 — Menú repetitivo con `switch` y `do-while`

**Enunciado:**
Desarrollar un algoritmo que muestre un menú de opciones que se repita continuamente hasta que el usuario elija la opción de **Salir**:

```
1. Sumar dos números
2. Restar dos números
3. Salir
```

El programa debe seguir mostrando el menú después de cada operación, hasta que el usuario elija la opción 3.

**Requisitos:**
- Debe combinar un bucle `do-while` / `Repetir...Hasta Que` (para que el menú se repita) con un `switch` / `Segun` (para procesar la opción elegida).
- Si el usuario ingresa una opción inválida (por ejemplo, 7), debe mostrar un mensaje de error y volver a mostrar el menú (no debe cerrar el programa).

**Entregable:**
- [ ] Algoritmo en PSeint
- [ ] Código en C#
