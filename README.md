# 💻 Programación Fundamental con C# y .NET

Repositorio oficial con el material de estudio, guías técnicas, ejemplos prácticos, ejercicios y proyectos desarrollados a lo largo del curso de **Programación Fundamental**.

---

## 🎯 Objetivo del Curso

Desarrollar la lógica algorítmica y las habilidades de resolución de problemas mediante el aprendizaje de los fundamentos de la programación orientada a objetos utilizando **C#** y la plataforma **.NET**.

---

## 🛠️ Tecnologías y Herramientas

* **Lenguaje:** C#
* **Plataforma / SDK:** .NET SDK
* **Editor de Código:** Visual Studio Code
* **Extensiones recomendadas:** C# Dev Kit
* **Control de Versiones:** Git & GitHub

---
