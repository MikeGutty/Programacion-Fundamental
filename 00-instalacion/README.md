# Instalación y Configuración del Entorno de Desarrollo

Antes de comenzar con los contenidos de **Programación I**, es necesario preparar el entorno de desarrollo que utilizaremos durante la materia.

En esta asignatura trabajaremos principalmente con:

- C#
- .NET
- Visual Studio Code
- C# Dev Kit

## 🎯 Objetivo

Al finalizar esta guía, el estudiante deberá contar con un entorno de desarrollo correctamente configurado para poder crear, ejecutar y probar programas utilizando **C# y .NET**.

## 🛠️ Software necesario

Para comenzar, será necesario instalar las siguientes herramientas:

1. **.NET SDK**
2. **Visual Studio Code**
3. **Extensión C# Dev Kit**

## 📖 Guía de instalación

Sigue paso a paso la guía de configuración:

👉 [Ver guía de instalación y configuración](configuracion.md)

## ✅ Verificación

Una vez finalizada la instalación, puedes verificar que .NET se encuentra correctamente instalado ejecutando el siguiente comando en la terminal:

```bash
dotnet --version
```
